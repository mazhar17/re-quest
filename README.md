# Amanah · Renewable Energy Quest

An offline, self-contained gamified undergraduate Renewable Energy course companion.

Open `renewable-energy-quest.html` in any modern browser. It covers energy foundations, solar PV, solar thermal/CSP, wind, hydropower, ocean energy, bioenergy, geothermal energy, and storage/system design.

The interface uses Islamic geometric design and diagrams of inanimate engineering systems only. It has no external runtime dependencies, accounts, trackers, music, or animate imagery.

## Publishing with GitHub Pages

After pushing this folder to a repository, set GitHub Pages to deploy from the repository's branch and the `/re-quest` folder if the repository supports that source layout. Alternatively, move the HTML to a Pages root or use a workflow that publishes this folder as the site artifact.
